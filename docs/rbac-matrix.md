## Record-level rules (in addition to the matrix)

| Rule | Where enforced |
|---|---|
| Lead visibility: `leads.view_all` → all; `leads.view_team` → own + same team; `leads.view_own` → own only | `canViewLead` (src/lib/permissions/access.ts); backend query scoping |
| Editing a lead requires `leads.update` **and** visibility of that lead | `canEditLead` |
| Reassigning requires `leads.assign`; target must be inside the assigner's scope | demo adapter `assignableUsers`; backend assignment service |
| Records outside scope respond **404**, not 403, so their existence isn't revealed | demo adapter; backend contract |
| Duplicate checks reveal only visible matches; others are counted, not shown | `findDuplicates` |
| Auditor is read-only everywhere | role matrix + tests |
| Client users get no internal permissions; portal access is a separate, client-scoped surface (Sprint 4) | role matrix |
